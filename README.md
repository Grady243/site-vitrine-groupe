# Site Vitrine - Projet de Groupe

## 📌 Description du projet
Ce projet est un **site vitrine fictif** développé dans le cadre d’un travail de groupe.  
Le site a pour objectif de présenter une entreprise de classement de dossiers de manière claire et moderne, en utilisant uniquement **HTML et CSS**.  
Le design est basé sur une **maquette image**, qui a été reproduite fidèlement en code.

---

## 🚀 Sections du site
Le site est découpé en plusieurs sections :

1. **Hero Section**  
   - Navbar (logo à gauche, menu à droite)  
   - Image centrale en flat design  
   - Titre, paragraphe et bouton “Get Started”  

2. **Services Section**  
   - 4 cards (2 lignes × 2 colonnes)  
   - Chaque card contient une icône, un titre et un paragraphe  

3. **How We Work Section**  
   - Image à gauche  
   - Titre, paragraphe et bouton “See How We Work” à droite  

4. **Sign Up Section**  
   - Input email et bouton “Get Started”  
   - Placée entre Testimonials et Footer  

5. **Testimonials Section**  
   - Témoignages clients sous forme de cards  

6. **Footer**  
   - Informations de contact, liens, réseaux sociaux  

7. **Responsive Web Design**  
   - Tout le site est optimisé pour desktop, tablette et mobile

## Organisation du projet en équipe

-Chaque issue est assignée à un membre

-Les branches correspondent aux issues (ex : feature-hero)
